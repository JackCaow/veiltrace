# Contributing

Run `npm ci`, `npm run typecheck`, `npm test`, and `npm run benchmark` before
submitting changes. Include both successes and misses, image dimensions, device
pixel ratio, channel, amplitude, namespace, runtime and platform in measurements.
Use synthetic or explicitly consented data. Do not commit screenshots containing
private messages, tokens or personal information.

Protocol changes must update the protocol identifier, tests and documentation.
Do not lower rejection thresholds or remove failing samples just to improve a
headline recovery rate. Visual acceptance requires a separate human review.

Use conventional commit messages. New algorithms and assets must have compatible
licenses; do not include research model weights with ambiguous or noncommercial
terms. Bug reports and reproducible fixtures are welcome.
